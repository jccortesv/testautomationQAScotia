# testautomationQAScotia
This is the repository in which the automation test case was created for Quality Assurance Automation Engineer position at Scotiabank.

This project vas developed on Eclipse IDE 2026. To install this project, you have to configure the run configurations as this:  JRE, JUnit and Cucumber Run configurations (Execution environment: JavaSE-21), Selenium (4.44.0). All dependencies are installed. Due to timelines and work related to my actual project, Allure and POM requirement is pending. Everything else is working as expected. The test case automated here is the one related to a short E2E of the whole process of selecting a product and doing the checkout for the standard_user user.
